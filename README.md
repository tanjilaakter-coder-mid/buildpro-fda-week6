# 🚀 BuildPro - Week 6 Landing Page

BuildPro Week 6 is a modern, responsive, and feature-rich Next.js landing page built with Tailwind CSS, TypeScript, and modern web development best practices.

---

## ✨ Features

* **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewports.
* **Modern UI Components:** Includes interactive navigation bars, feature cards, and dynamic sections.
* **Static Page Generation:** Pre-rendered for optimal loading speed and SEO performance.
* **Dark/Light Theme Support:** Built-in theme toggling capabilities using modern providers.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router & Turbopack)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Deployment:** [Vercel](https://vercel.com/)
